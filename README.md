## The entry

> This meeting is cancelled: the answer is yes, the deadline is Friday, and the email you're reading just saved us an hour.

One line, one sentence — the sentence that replaces the entire meeting. It *is* the email that should have replaced the meeting, which is the whole joke.

## How it works

`main.py` writes that single line, deterministically, to `/output/entry.txt`. It also self-checks the competition gate before and after writing: UTF-8 text, 1–200 characters, not only whitespace, exactly one line and one sentence.

```sh
python3 main.py
```
